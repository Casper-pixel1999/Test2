# Бургерная (Burger Rush)

Аркадно-idle игра про бургерный ресторан для **Яндекс Игр**.

Оригинальный IP (не связан с Burger Please!). Управление: WASD / стрелки + виртуальный джойстик. Цикл: готовь котлеты → собирай бургеры → обслуживай клиентов → убирай столы → улучшай ресторан.

## Как понять игру за 20 секунд

Цветные зоны на полу:
- **оранжевый ГРИЛЬ** — жарь и забирай котлеты
- **жёлтая СБОРКА** — сложи бургеры
- **зелёная СТОЙКА** — отдай заказ
- **синие СТОЛЫ** — клиенты едят; **грязный стол** нужно убрать

Подсказка сверху и пульсирующая стрелка показывают только следующий шаг. Подойди к станции (или **E / нажми**). Повар — человечек в колпаке, над головой стопка котлет/бургеров. У клиентов пузырь 🍔 и полоска терпения (зелёная → красная).

## Запуск локально

Нужен любой статический сервер (модули ES и путь `/sdk.js`):

```bash
cd burger-rush
# Python
python3 -m http.server 8080
# или Node
npx --yes serve -l 8080 .
```

Откройте http://localhost:8080 — SDK Яндекса отсутствует, используется **mock** (LoadingAPI, GameplayAPI, rewarded video).

Либо откройте `index.html` через Live Server в IDE.

## Сборка ZIP для консоли Яндекс Игр

Игра уже статическая (без сборщика). Упакуйте содержимое корня проекта:

```bash
cd burger-rush
zip -r burger-rush-yandex.zip index.html sdk.js css js README.md
```

В консоли Яндекс Игр загрузите `burger-rush-yandex.zip`. Точка входа: `index.html`.

> На платформе Яндекс подставляет свой `/sdk.js`. Локальный `sdk.js` в архиве — заглушка и не мешает.

## Хуки Yandex Games SDK

| Хук | Где |
|-----|-----|
| Загрузка `/sdk.js` | `index.html` |
| `YaGames.init()` | `js/yandex.js` → `initYandex()` |
| `LoadingAPI.ready()` | после готовности игры в `js/main.js` |
| `GameplayAPI.start/stop` | старт игры, пауза, реклама, `visibilitychange` |
| `game_api_pause` / `game_api_resume` | подписка в `yandex.js`, пауза оверлея |
| `environment.i18n.lang` | выбор RU/EN в `main.js` |
| Rewarded video (`adv.showRewardedVideo`) | кнопка «🎬 x2», двойная прибыль 60 сек |
| `player.setData` / `getData` | облачное сохранение (опционально) + `localStorage` |

Локально при отсутствии `YaGames` все API эмулируются в `js/yandex.js`.

## Управление

- **Движение:** WASD / стрелки / джойстик слева
- **Взаимодействие:** автоматически при подходе к станции (гриль, сборка, стойка, грязный стол); Space / E / tap. Станция в радиусе подсвечивается, появляется «E / нажми».
- **Магазин:** кнопка 🛒 — скорость, вместимость, прибыль, гриль, столы, официант, уборщик
- **Реклама:** 🎬 x2 — удвоенная прибыль на 60 секунд

## Сохранение

- `localStorage` ключ `burger_rush_save_v1`
- При наличии игрока Яндекса — периодический `player.setData`

## Структура

```

css/style.css
js/main.js      # старт, UI, пауза
js/yandex.js    # SDK + mock

js/game.js      # геймплей canvas

```

## Лицензия

Код и ассеты (процедурный canvas) — оригинальные, для публикации на Яндекс Играх владельцем репозитория.


## Модерация Яндекс Игр (v1.2)

- Rewarded (кнопка x2) + fullscreen interstitial при закрытии магазина (кулдаун ~90 с игрового времени).
- `contextmenu` / `selectstart` отключены.
- `GameplayAPI.stop` в магазине и на паузе/рекламе.
- Цветные зоны, пошаговый туториал со стрелкой, читаемый HUD, персонажи не кружки.
